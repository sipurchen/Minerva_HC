# Minerva HC Skill Plan

## Project Overview

Create a public, MIT-licensed Codex Skill inspired by Minerva University's publicly documented Habits of Mind and Foundational Concepts. The repository must remain self-contained, source-attributed, and free of private workspace data.

## Objectives

- Translate a small, verifiable set of public HC examples into an operational Codex workflow.
- Support project analysis, curriculum design, decision review, and cross-domain transfer.
- Use behavioral evidence and a 1–5 application rubric without reproducing proprietary course materials.
- Publish research on similar repositories and explain this Skill's distinct scope.
- Pass structure, UTF-8, secret, identity, absolute-path, and private-project scans before publication.

## Model Assignment

- SipurCodex: primary research, Skill design, implementation, validation, sanitization, Git publication, and pull request.
- External models: none.

## File Structure

- README.md: public positioning, installation, usage, sources, and disclaimer.
- LICENSE: standard MIT License.
- docs/SIMILAR_REPOS.md: primary-source comparison of related public repositories.
- skills/minerva-hc-thinking/SKILL.md: concise Skill entrypoint and workflow.
- skills/minerva-hc-thinking/references/hc-framework.md: public-source HC map, transfer tasks, and rubric.
- skills/minerva-hc-thinking/agents/openai.yaml: Codex UI metadata and invocation policy.

## Task Breakdown

1. Verify official public definitions and inspect similar public repositories.
2. Initialize the Skill with the bundled Skill creator.
3. Replace scaffolding with a narrow, evidence-based workflow.
4. Add public documentation and source attribution.
5. Run Skill validation and sanitization gates.
6. Commit only reviewed files, push the feature branch, and open a pull request.

## Open Questions

- The public HC set has changed over time. This project will not claim to reproduce a current or complete Minerva catalog.
- Public examples will be paraphrased and cited; non-public rubrics, course notes, and student materials are out of scope.
- The Skill will expose checkable artifacts and concise rationale, not hidden chain-of-thought.
